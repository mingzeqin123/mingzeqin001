# 短视频智能封面挑选指南

本文档介绍 `pages/cover-review/cover-review` 页面提供的短视频封面自动挑选与人工复核能力，帮助你快速理解功能入口、操作步骤与底层实现要点。

## 功能概览

- **自动抽帧评分**：基于视频时长按均匀时间间隔抽取画面，并通过亮度、对比度、边缘强度等指标计算综合得分，默认选出评分最高的若干张封面。
- **人工复核**：在播放页随时捕捉当前帧加入候选，并通过点选快速确认最终封面集合。
- **进度与保存**：自动抽帧时显示百分比进度，可预览已选封面并一键保存到系统相册（需授权）。

## 使用步骤

1. 在开发者工具或真机上进入 `封面智能挑选` 页面：
   ```js
   wx.navigateTo({ url: '/pages/cover-review/cover-review' })
   ```
   > 若希望将其设为首页，可在 `app.json` 中将该页面放在 `pages` 数组首位。

2. 点击“选择短视频”，从相册或相机挑选素材。页面会自动展示时长、分辨率及帧率等基础信息。

3. 根据需求调整“抽帧数量”和“自动入选数量”滑块，点击“自动选封面”启动分析。分析过程中会显示实时进度条。

4. **人工复核**：
   - 播放或拖动视频进度至关键画面，点击“捕捉当前帧”手动加入候选。
   - 候选列表可通过点击卡片切换是否入选，蓝色边框代表已勾选。
   - “清空候选”可恢复初始状态重新评估。

5. 在候选卡片下方可选择：
   - “预览入选封面”全屏查看目前勾选的图片。
   - “保存到相册”批量保存图片（第一次操作需在授权弹窗中允许写入相册）。

## 技术说明

- **抽帧策略**：
  - 通过 `wx.createVideoContext` 与 `canvas` 2D 渲染上下文配合，逐帧 `seek` 并绘制到隐藏画布。
  - 使用 `wx.canvasToTempFilePath` 导出临时图片，再利用 `CanvasRenderingContext2D.getImageData` 读取像素数据。

- **评分指标**：
  - 亮度均值与方差衡量整体曝光与对比度。
  - 邻域灰度差估计边缘清晰度，提升清楚、有主体的画面得分。
  - 过曝/过暗像素比例用于给出曝光惩罚。

- **去重策略**：
  - 相邻抽帧的平均像素差异低于阈值 (0.08) 时跳过，减少相似画面。
  - 手动捕捉帧会直接加入并默认勾选，确保人工复核权重更高。

- **兼容性要求**：
  - 需基础库 ≥ 2.9.0 才能通过 `fields({ node: true })` 获取 `video` 与 `canvas` 节点。
  - 若设备不支持 2D `canvas` 节点或相册权限受限，页面会提示手动捕捉或授权。

## 调试与限制

- 开发者工具模拟器对 `canvas` 抽帧支持有限，建议在真机上验证自动抽帧能力。
- 对于超长或高码率视频，抽帧可能耗时较长，可调低“抽帧数量”减轻负载。
- 当前评分算法基于通用图像质量指标，如需更精确的人像 / 商品检测，可在后续迭代中接入云函数或本地 AI 模型。
