# 大文件手机号和地址提取工具

这是一个专门用于从大文件（支持1GB+）中提取手机号码和地址信息的Python工具。

## 功能特点

- **高效处理大文件**：使用分块读取技术，可以处理1GB以上的大文件而不会占用过多内存
- **智能手机号识别**：支持多种手机号格式（标准11位、带国际区号、带分隔符等）
- **地址智能提取**：基于正则表达式和关键词匹配，提取各种格式的中文地址
- **编码自适应**：自动处理UTF-8和GBK编码文件
- **结果去重**：自动去除重复的手机号和地址
- **进度显示**：处理大文件时显示实时进度

## 支持的手机号格式

- 标准格式：`13812345678`
- 国际区号：`+86 13812345678`
- 带空格：`138 1234 5678`
- 带横线：`138-1234-5678`
- 带括号：`(+86)138-1234-5678`

## 支持的地址格式

- 完整地址：`北京市朝阳区建国路88号SOHO现代城A座1201室`
- 简化地址：`建国路88号`
- 小区地址：`中关村软件园二期东升科技园B区8号楼3层`
- 商业地址：`陆家嘴金融贸易区世纪大道100号环球金融中心50楼`

## 安装要求

```bash
python 3.6+
```

无需额外依赖包，使用Python标准库。

## 使用方法

### 基本用法

```bash
python extract_phone_address.py <文件路径>
```

### 高级选项

```bash
python extract_phone_address.py <文件路径> --chunk-size 16384 --output-dir my_results
```

参数说明：
- `file_path`：要处理的文件路径（必需）
- `--chunk-size`：每次读取的字节数，默认8192（8KB）
- `--output-dir`：输出目录，默认为`extraction_results`

### 示例

```bash
# 处理示例文件
python extract_phone_address.py sample_data.txt

# 处理大文件，使用更大的块大小提高性能
python extract_phone_address.py large_file.txt --chunk-size 32768

# 指定输出目录
python extract_phone_address.py data.txt --output-dir results_2024
```

## 输出文件

脚本会在指定的输出目录中创建以下文件：

1. **extracted_phones.txt**：提取到的所有手机号（每行一个）
2. **extracted_addresses.txt**：提取到的所有地址（每行一个）
3. **extraction_stats.json**：统计信息（包含数量和文件大小）

## 性能优化

### 处理大文件的建议

1. **调整块大小**：
   - 小文件（<100MB）：使用默认的8KB
   - 中等文件（100MB-1GB）：使用16KB-32KB
   - 大文件（>1GB）：使用32KB-64KB

2. **内存使用**：
   - 脚本内存使用量通常在50-200MB之间
   - 与文件大小无关，只与块大小和缓冲区大小相关

3. **处理速度**：
   - 典型速度：10-50MB/s（取决于硬件和文件内容）
   - SSD比HDD快2-3倍

## 技术实现

### 核心算法

1. **分块读取**：将大文件分成小块处理，避免内存溢出
2. **缓冲区管理**：处理跨块的文本，确保不遗漏信息
3. **正则匹配**：使用多个正则表达式模式提高匹配准确率
4. **去重处理**：使用集合自动去除重复项

### 正则表达式模式

**手机号模式**：
```python
r'1[3-9]\d{9}'           # 标准11位
r'(\+86\s*)?1[3-9]\d{9}' # 带国际区号
r'1[3-9]\d{4}\s*\d{4}'   # 中间有空格
r'1[3-9]\d{4}-\d{4}'     # 中间有横线
```

**地址模式**：
```python
# 完整地址格式
r'[^\s]{2,10}[省市区县][^\s]{2,20}[市区县镇乡村][^\s]{2,50}[路街巷弄号栋楼室][^\s\n]{0,30}'

# 简化地址格式
r'[^\s]{2,20}[路街巷弄][^\s]{1,20}号[^\s\n]{0,20}'

# 小区地址格式
r'[^\s]{2,20}小区[^\s]{0,30}[栋楼][^\s]{0,10}[室号][^\s\n]{0,10}'
```

## 常见问题

### Q: 如何处理编码问题？
A: 脚本会自动尝试UTF-8编码，如果失败会尝试GBK编码。

### Q: 内存不足怎么办？
A: 减小`--chunk-size`参数值，比如使用4096或2048。

### Q: 提取结果不准确怎么办？
A: 可以修改脚本中的正则表达式模式，或调整地址关键词列表。

### Q: 支持其他国家的手机号吗？
A: 当前版本主要针对中国手机号，可以修改正则表达式支持其他格式。
