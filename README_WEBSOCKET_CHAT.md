# WebSocket 聊天功能实现

这是一个基于 WebSocket 的实时聊天系统，包含 Node.js 后端服务器和微信小程序前端。

## 功能特性

- ✅ 实时消息发送与接收
- ✅ 多用户在线聊天
- ✅ 房间系统支持
- ✅ 用户进入/离开提醒
- ✅ 输入状态提示
- ✅ 断线自动重连
- ✅ 消息长按操作（复制、删除）
- ✅ 在线用户列表
- ✅ 心跳检测
- ✅ 优雅的UI设计
- ✅ 响应式布局
- ✅ 暗黑模式支持

## 安装和运行

### 1. 后端服务器设置

```bash
# 安装依赖
npm install

# 启动服务器
npm start

# 或者使用开发模式（自动重启）
npm run dev
```

服务器将在 `http://localhost:8080` 启动。

### 2. 微信小程序设置

1. 打开微信开发者工具
2. 导入项目，选择这个目录作为项目根目录
3. 修改 `pages/chat/chat.js` 中的服务器地址：
   ```javascript
   serverUrl: 'ws://your-server-ip:8080'
   ```
4. 在微信开发者工具中启用"不校验合法域名"选项
5. 编译并运行小程序

## 使用说明

### 基本使用流程

1. 启动后端服务器
2. 在微信小程序中打开聊天功能
3. 输入房间ID或选择加入默认房间
4. 开始聊天！

### 房间系统

- **默认房间**: 所有用户都可以加入的公共房间
- **自定义房间**: 输入特定房间ID创建或加入房间
- **随机房间**: 系统生成随机房间ID

### 聊天功能

- **发送消息**: 在输入框中输入文字，点击发送或按回车
- **消息操作**: 长按消息可以复制或删除
- **在线状态**: 右上角显示在线用户数量，点击查看用户列表
- **输入提示**: 当有用户正在输入时会显示提示
- **自动重连**: 网络断开时会自动尝试重连

## 服务器 API

### WebSocket 消息格式

#### 客户端发送消息

```javascript
// 加入房间
{
  "type": "join",
  "roomId": "room123",
  "nickname": "用户昵称",
  "avatar": "头像URL"
}

// 发送聊天消息
{
  "type": "message",
  "content": "消息内容"
}

// 输入状态
{
  "type": "typing",
  "isTyping": true/false
}

// 心跳检测
{
  "type": "ping"
}
```

#### 服务器推送消息

```javascript
// 连接成功
{
  "type": "connected",
  "clientId": "客户端ID",
  "timestamp": 1234567890
}

// 加入房间成功
{
  "type": "joined",
  "roomId": "房间ID",
  "users": [...],
  "timestamp": 1234567890
}

// 聊天消息
{
  "type": "message",
  "id": "消息ID",
  "content": "消息内容",
  "user": {
    "id": "用户ID",
    "nickname": "昵称",
    "avatar": "头像"
  },
  "timestamp": 1234567890
}

// 用户加入/离开
{
  "type": "user_joined" | "user_left",
  "user": {...},
  "users": [...],
  "timestamp": 1234567890
}

// 输入状态
{
  "type": "typing",
  "user": {...},
  "isTyping": true/false,
  "timestamp": 1234567890
}
```

## 部署说明

### 开发环境

在开发环境中，可以直接使用 `localhost:8080` 作为服务器地址。

### 生产环境

1. 将服务器部署到云服务器
2. 确保服务器支持 WebSocket
3. 配置 HTTPS/WSS（如果需要）
4. 更新小程序中的服务器地址
5. 在微信公众平台配置合法域名

### 推荐部署平台

- **腾讯云**: 云服务器 + 负载均衡
- **阿里云**: ECS + SLB
- **Heroku**: 免费托管（有限制）
- **Vercel**: Serverless 部署

## 技术实现细节

### 后端技术栈

- **Node.js**: 服务器运行时
- **ws**: WebSocket 库
- **内存存储**: 用户和房间信息存储

### 前端技术栈

- **微信小程序**: 原生框架
- **WebSocket API**: 实时通信
- **本地存储**: 用户信息缓存

### 核心特性实现

1. **房间管理**: 使用 Map 存储房间和用户关系
2. **消息广播**: 向房间内所有用户发送消息
3. **连接管理**: 心跳检测和自动重连
4. **状态同步**: 实时更新用户列表和输入状态
5. **错误处理**: 优雅处理连接异常和消息失败

## 注意事项

1. **网络要求**: 确保服务器和客户端网络连接稳定
2. **域名配置**: 生产环境需要配置合法域名
3. **并发限制**: 当前版本使用内存存储，大量用户时需要优化
4. **消息持久化**: 消息不会持久化存储，重启服务器会丢失
5. **安全考虑**: 生产环境建议添加用户认证和消息过滤

## 常见问题

### Q: 连接失败怎么办？
A: 检查服务器是否启动，网络是否正常，域名配置是否正确。

### Q: 消息发送失败？
A: 检查 WebSocket 连接状态，确认服务器正常运行。

### Q: 无法获取用户信息？
A: 确保小程序有获取用户信息的权限。

### Q: 自动重连不工作？
A: 检查网络状态，确认重连逻辑是否正确执行。
