# 防恶意评论系统说明

## 系统概述

本系统为微信小程序提供了完整的防恶意评论解决方案，包含多层防护机制和完善的管理后台。

## 主要功能

### 1. 反垃圾评论机制

#### 内容检测
- **敏感词过滤**: 自动检测政治敏感、色情、暴力、广告等违规内容
- **垃圾模式识别**: 检测重复字符、过多特殊符号、异常字符比例等
- **内容长度限制**: 防止过短或过长的无效评论

#### 用户行为限制
- **频率限制**: 
  - 每分钟最多3条评论
  - 每小时最多20条评论
  - 每天最多100条评论
  - 最小评论间隔10秒
- **风险等级评估**: 基于账户年龄、评论历史、举报次数等因素

#### 验证机制
- **验证码**: 高风险用户需要输入验证码
- **人工审核**: 高风险内容自动进入审核队列

### 2. 用户管理系统

#### 黑名单机制
- **自动拉黑**: 被举报次数超过阈值自动加入黑名单
- **手动管理**: 管理员可手动添加/移除黑名单用户
- **永久存储**: 黑名单信息持久化保存

#### 举报系统
- **多种举报类型**: 垃圾信息、辱骂攻击、色情内容、广告推广、政治敏感等
- **自动处理**: 同一评论被举报3次以上自动屏蔽
- **举报记录**: 完整的举报历史和处理状态

### 3. 管理后台

#### 数据统计
- 总评论数、今日评论数
- 待处理举报数、已屏蔽评论数
- 实时数据更新

#### 举报管理
- 查看所有举报记录
- 按状态筛选（待处理/全部）
- 确认违规或驳回举报

#### 评论管理
- 查看所有评论（包括已屏蔽）
- 按类型筛选（全部/已屏蔽/高风险）
- 手动屏蔽/取消屏蔽评论
- 删除评论功能

#### 黑名单管理
- 查看所有黑名单用户
- 搜索用户功能
- 添加/移除黑名单用户

#### 系统设置
- 调整反垃圾参数
- 数据清理功能
- 系统重置功能

```
utils/                  # 工具类

```

### 关键算法

#### 1. 敏感词检测
使用关键词匹配算法，支持:
- 大小写不敏感匹配
- 多语言支持
- 动态词库更新

#### 2. 垃圾内容识别
通过正则表达式检测:
- 重复字符模式
- 特殊符号比例
- 数字内容比例
- 异常格式模式

#### 3. 用户风险评估
综合考虑:
- 账户注册时间
- 历史评论频率
- 被举报次数
- 评论质量得分

#### 4. 相似度检测
使用编辑距离算法检测:
- 用户重复评论
- 内容相似度计算
- 防刷屏机制

## 使用方法

### 1. 用户端使用
1. 进入评论页面
2. 输入评论内容
3. 系统自动检测内容合规性
4. 高风险用户需要输入验证码
5. 发布成功或进入审核队列

### 2. 管理员使用
1. 进入管理后台页面
2. 输入管理员密码（默认: admin123）
3. 查看统计数据和待处理事项
4. 处理举报、管理评论和黑名单
5. 调整系统参数

### 3. 举报流程
1. 点击评论的"举报"按钮
2. 选择举报原因
3. 填写详细描述（可选）
4. 提交举报
5. 系统自动处理或进入人工审核

## 配置参数

### 反垃圾参数
- `maxCommentsPerMinute`: 每分钟最大评论数（默认3）
- `maxCommentsPerHour`: 每小时最大评论数（默认20）
- `maxCommentsPerDay`: 每天最大评论数（默认100）
- `minCommentInterval`: 最小评论间隔（默认10秒）
- `maxCommentLength`: 评论最大长度（默认500字）
- `minCommentLength`: 评论最小长度（默认2字）

### 自动处理阈值
- `autoBlockThreshold`: 自动屏蔽举报阈值（默认3次）
- `autoBlacklistThreshold`: 自动拉黑举报阈值（默认10次）

## 数据存储

### 本地存储键值
- `app_comments`: 所有评论数据
- `comment_reports`: 举报记录
- `blocked_comments`: 被屏蔽评论ID列表
- `user_blacklist`: 黑名单用户数据
- `user_profiles`: 用户资料信息
- `admin_settings`: 管理员设置
