# 网易云直播系统集成文档

## 📺 系统概述

本项目成功集成了基于网易云推流平台的完整直播系统，为微信小程序提供了专业级的直播功能。系统包含推流端（主播）、拉流端（观众）、聊天系统、礼物系统等完整功能模块。

## 🏗️ 系统架构

```
直播系统架构
├── 配置层 (config/)
│   └── live-config.js          # 网易云配置和系统参数
├── API层 (utils/)
│   ├── live-api.js             # 直播API和网易云SDK封装
│   ├── chat-manager.js         # 聊天管理器
│   └── live-utils.js           # 工具函数库
├── 页面层 (pages/live/)
│   ├── live-list.*             # 直播大厅页面
│   ├── live-push.*             # 推流页面（主播端）
│   ├── live-watch.*            # 观看页面（观众端）
│   └── live-room.*             # 房间管理页面
└── 应用层
    ├── app.js                  # 全局配置和初始化
    └── app.json                # 小程序配置
```

## 🚀 核心功能

### 1. 直播推流（主播端）
- **实时推流**: 基于网易云推流技术，支持高清视频推流
- **美颜功能**: 内置美颜、美白、滤镜等功能
- **推流控制**: 开始/停止/暂停推流，摄像头切换
- **实时统计**: 观看人数、点赞数、直播时长统计
- **聊天互动**: 与观众实时聊天互动

### 2. 直播观看（观众端）
- **流畅播放**: 支持多种拉流协议（HTTP-FLV、HLS、RTMP）
- **自适应码率**: 根据网络状况自动调整播放质量
- **互动功能**: 聊天、送礼、点赞等互动功能
- **弹幕系统**: 实时弹幕显示和管理
- **全屏播放**: 支持横屏全屏观看

### 3. 聊天系统
- **实时消息**: 基于WebSocket的实时消息传输
- **消息类型**: 支持文本、表情、礼物、系统消息
- **内容过滤**: 敏感词过滤和内容审核
- **消息管理**: 消息历史、搜索、删除等功能

### 4. 房间管理
- **房间创建**: 支持自定义房间信息、封面、标签
- **权限控制**: 公开/私密房间，密码保护
- **参数配置**: 视频质量、码率、帧率等参数设置
- **功能开关**: 录制、弹幕、礼物等功能开关

## 📋 配置说明

### 网易云配置 (config/live-config.js)

```javascript
const LIVE_CONFIG = {
  netease: {
    appKey: 'YOUR_NETEASE_APP_KEY',        // 网易云信AppKey
    appSecret: 'YOUR_NETEASE_APP_SECRET',   // 网易云信AppSecret
    streaming: {
      pushDomain: 'push.your-domain.com',   // 推流域名
      pullDomain: 'pull.your-domain.com',   // 拉流域名
      pushProtocol: 'rtmp',                 // 推流协议
      pullProtocol: 'http-flv',             // 拉流协议
      bitrate: { video: 1000, audio: 128 }, // 码率设置
      resolution: { width: 720, height: 1280 }, // 分辨率
      fps: 30                               // 帧率
    }
  }
}
```

## 🛠️ 部署指南

### 1. 环境准备

1. **微信开发者工具**: 版本 1.05.0+
2. **小程序基础库**: 版本 2.9.0+
3. **网易云信账号**: 注册并获取AppKey和AppSecret
4. **服务器环境**: 用于API接口和消息推送

### 2. 配置步骤

1. **更新配置文件**
   ```javascript
   // config/live-config.js
   const LIVE_CONFIG = {
     netease: {
       appKey: 'YOUR_ACTUAL_APP_KEY',
       appSecret: 'YOUR_ACTUAL_APP_SECRET',
       // ... 其他配置
     }
   }
   ```

2. **配置推拉流域名**
   - 在网易云信控制台配置推流域名
   - 配置拉流域名和CDN加速
   - 设置鉴权和安全策略

3. **部署后端服务**
   - 实现直播间管理API
   - 实现用户认证和权限控制
   - 配置消息推送服务

### 3. 测试验证

1. **功能测试**

   - 进入直播间
   - 验证播放流畅性

## 📱 使用说明

### 主播端操作流程

1. **创建直播间**
   - 进入"创建直播间"页面
   - 填写房间信息（名称、描述、分类）
   - 选择封面和标签
   - 配置高级设置

2. **开始直播**
   - 点击"开始直播"按钮
   - 系统自动获取推流地址
   - 开始实时推流
   - 与观众互动

3. **直播管理**
   - 实时查看观看数据
   - 管理聊天消息
   - 调整美颜参数
   - 控制推流质量

### 观众端操作流程

1. **浏览直播**
   - 进入直播大厅
   - 浏览热门直播间
   - 搜索感兴趣的内容

2. **观看直播**
   - 点击进入直播间
   - 观看实时直播内容
   - 参与聊天互动
   - 送礼支持主播

## 🚨 常见问题

### Q1: 推流连接失败
**解决方案**: 
- 检查网络连接状态
- 验证推流地址有效性
- 确认摄像头和麦克风权限

### Q2: 播放卡顿或延迟高
**解决方案**:
- 调整播放缓冲区设置
- 切换到更稳定的网络
- 降低推流码率和分辨率

### Q3: 聊天消息不显示
**解决方案**:
- 检查WebSocket连接状态
- 验证消息格式正确性
- 确认服务器消息推送正常
