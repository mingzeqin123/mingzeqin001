# 直播系统开发文档

## 🎯 项目概述

本项目是一套完整的直播系统，基于微信小程序前端 + Node.js后端 + 网易云推流平台的架构，提供完整的直播推流、观看、互动功能。

## 🚀 功能特性

### 核心功能
- ✅ **直播推流**：支持实时视频推流
- ✅ **直播观看**：支持多协议拉流播放
- ✅ **实时弹幕**：支持实时弹幕互动
- ✅ **礼物系统**：支持虚拟礼物赠送
- ✅ **用户管理**：完整的用户体系
- ✅ **直播管理**：直播间创建和管理

### 技术特性
- ✅ **高并发**：支持万级并发观看
- ✅ **低延迟**：端到端延迟<3秒
- ✅ **多协议**：支持RTMP、HLS、HTTP-FLV
- ✅ **实时通信**：基于WebSocket的实时通信
- ✅ **跨平台**：支持微信小程序、H5、APP

### 核心功能实现

#### 1. 直播推流
```javascript
// 初始化推流器
const livePusher = wx.createLivePusherContext('livePusher', this);

// 开始推流
livePusher.start({
  url: pushUrl,
  success: () => {
    console.log('推流开始成功');
  }
});
```

#### 2. 直播观看
```javascript
// 初始化播放器
const livePlayer = wx.createLivePlayerContext('livePlayer', this);

// 开始播放
livePlayer.play({
  url: streamUrl,
  success: () => {
    console.log('开始观看直播');
  }
});
```

#### 3. 实时弹幕
```javascript
// 发送弹幕
socket.emit('send_danmaku', {
  content: '弹幕内容',
  color: '#ffffff'
});

// 接收弹幕
socket.on('danmaku', (danmaku) => {
  this.addDanmaku(danmaku);
});
```

## 🔧 网易云推流集成

### 1. 平台介绍
网易云推流平台提供专业的直播推流服务，具有以下优势：
- 高可用性：99.9%服务可用性
- 低延迟：端到端延迟<3秒
- 全球加速：CDN覆盖全球
- 多协议支持：RTMP、HLS、HTTP-FLV

### 2. 接入步骤
1. 注册网易云信账号
2. 创建应用获取AppKey和AppSecret
3. 配置环境变量
4. 集成SDK

### 3. 核心API
```javascript
// 创建推流频道
const channelInfo = await neteaseService.createChannel(roomId, title, cover);

// 获取推流地址
const pushInfo = await neteaseService.getPushUrl(roomId, title, cover);

// 获取频道状态
const status = await neteaseService.getChannelStatus(roomId);
```

## 📊 数据流程

### 直播推流流程
```
1. 用户点击"开始直播"
2. 前端请求推流地址
3. 后端调用网易云API获取推流地址
4. 前端初始化推流器并开始推流
5. 推流状态实时同步到后端
6. 后端广播直播状态给所有观众
```

### 直播观看流程
```
1. 用户进入直播间
2. 前端获取拉流地址
3. 初始化播放器开始播放
4. 建立WebSocket连接
5. 接收实时弹幕和礼物消息
6. 发送弹幕和礼物消息
```

## 🐛 常见问题

### 推流问题
1. **推流失败**
   - 检查推流地址格式
   - 验证网络连接
   - 确认推流参数

2. **推流中断**
   - 检查网络稳定性
   - 调整推流码率
   - 检查设备性能

### 播放问题
1. **播放失败**
   - 检查拉流地址
   - 验证网络连接
   - 确认播放器配置

2. **播放卡顿**
   - 降低推流码率
   - 使用CDN加速
   - 检查设备性能
