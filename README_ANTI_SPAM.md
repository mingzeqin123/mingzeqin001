# 防恶意评论系统

## 🛡️ 系统概述

本系统实现了一套完整的防恶意评论机制，包含前端验证、后端检测、用户行为分析等多个层面的保护措施，有效防止用户刷恶意评论。

## ✨ 主要特性

### 🔍 智能内容检测
- **敏感词过滤**: 实时检测并拦截包含敏感词的内容
- **垃圾内容识别**: 识别重复字符、特殊字符、联系方式等垃圾模式
- **内容质量评估**: 基于长度、词汇多样性、字符分布等指标评估内容质量
- **重复内容检测**: 使用文本相似度算法检测重复或高度相似的内容

### ⏰ 频率限制机制
- **多层限制**: 全局、用户、IP等多维度频率限制
- **动态冷却**: 根据用户行为动态调整冷却时间
- **智能阈值**: 可配置的评论频率阈值

### 👤 用户行为分析
- **行为追踪**: 记录用户评论频率、内容模式、时间分布等
- **异常检测**: 识别可疑的用户行为模式
- **风险评估**: 综合评估用户风险等级

### 🔐 验证码机制
- **智能触发**: 根据用户行为自动触发验证码
- **图形验证码**: 简单的数字验证码实现
- **刷新机制**: 支持验证码刷新

### 🚫 黑名单管理
- **自动拉黑**: 基于行为规则自动添加黑名单
- **手动管理**: 管理员可手动管理黑名单
- **白名单支持**: 支持白名单用户免检

## 🚀 快速开始

### 1. 前端集成

将评论页面集成到微信小程序中：

1. 复制 `pages/comments/` 目录到你的小程序项目
2. 在 `app.json` 中添加页面路径：
```json
{
  "pages": [
    "pages/comments/comments"
  ]
}
```

### 2. 后端部署

```bash
# 进入服务器目录
cd server

# 安装依赖
npm install

# 启动服务
npm start

# 开发模式
npm run dev
```

### 3. 运行测试

```bash
# 运行功能测试
node server/test.js

# 运行演示脚本
node demo.js
```

## 🔧 配置说明

### 敏感词库配置

```javascript
// 在 utils/antiSpam.js 中配置
const sensitiveWords = [
  '垃圾', '骗子', '傻逼', // 添加你的敏感词
  // ...
];
```

### 频率限制配置

```javascript
const thresholds = {
  maxCommentsPerMinute: 3,    // 每分钟最大评论数
  maxCommentsPerHour: 10,     // 每小时最大评论数
  maxCommentsPerDay: 50,      // 每天最大评论数
  maxSimilarityRatio: 0.8,    // 最大相似度比例
  maxSuspiciousActions: 5     // 最大可疑行为数
};
```

### 内容质量阈值

```javascript
const qualityWeights = {
  minLength: 3,           // 最小长度
  maxLength: 500,         // 最大长度
  minUniqueWords: 2,      // 最小唯一词数
  maxRepeatedChars: 5,    // 最大重复字符数
  maxSpecialChars: 10     // 最大特殊字符数
};
```
