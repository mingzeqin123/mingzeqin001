# 中文翻译成英文程序

一个简单易用的中文到英文翻译程序，支持本地词典翻译和在线API翻译两种模式。

## 功能特点

- 🚀 **双模式翻译**: 支持本地词典翻译和在线API翻译
- 📚 **丰富词典**: 内置常用中文词汇的英文翻译
- 💬 **交互式界面**: 友好的命令行交互界面
- 🔧 **命令行支持**: 支持直接通过命令行参数进行翻译
- 🌐 **在线翻译**: 集成在线翻译API，提供更准确的翻译结果

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 交互式模式

直接运行程序进入交互式翻译模式：

```bash
python translator.py
```

在交互模式中，您可以：
- 输入中文文本进行翻译
- 输入 `online` 切换到在线翻译模式
- 输入 `local` 切换到本地翻译模式
- 输入 `quit` 或 `exit` 退出程序

### 2. 命令行模式

直接在命令行中指定要翻译的中文文本：

```bash
python translator.py "你好世界"
```

输出：
```
中文: 你好世界
英文: Hello World
```

## 翻译模式说明

### 本地翻译模式
- 使用内置词典进行翻译
- 无需网络连接
- 翻译速度快
- 适合常用词汇翻译

### 在线翻译模式
- 使用在线翻译API
- 需要网络连接
- 翻译更准确
- 适合复杂句子翻译

## 示例

```bash
# 交互式模式
$ python translator.py
=== 中文翻译成英文程序 ===
输入 'quit' 或 'exit' 退出程序
输入 'online' 切换到在线翻译模式
输入 'local' 切换到本地翻译模式
----------------------------------------

请输入中文: 你好
英文翻译: Hello

请输入中文: 今天天气很好
英文翻译: Today [天] [气] [很] [好]

请输入中文: online
已切换到在线翻译模式

请输入中文: 今天天气很好
英文翻译: The weather is very nice today
```

## 扩展词典

您可以在 `ChineseToEnglishTranslator` 类的 `translation_dict` 中添加更多中文词汇的翻译，以扩展本地翻译功能。

## 注意事项

- 在线翻译功能需要网络连接
- 在线翻译API可能有使用限制
- 本地翻译对于复杂句子可能不够准确，建议使用在线翻译
