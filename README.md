# 文字重复片段提取工具

这个工具可以提取两段文字中连续重复超过指定字符数的片段。

## 文件说明

1. **`find_common_substrings.py`** - 基础版本，包含示例文字和完整功能
2. **`find_common_substrings_optimized.py`** - 优化版本，只显示最长的重复片段，避免显示重复的子串
3. **`find_common_substrings_interactive.py`** - 交互式版本，可以接受用户输入的两段文字

## 功能特点

- 提取两段文字中连续重复超过指定字符数的片段
- 显示重复片段的内容、长度和位置信息
- 提供上下文信息，方便查看重复片段的周围内容
- 支持自定义最小重复长度
- 避免显示重复的子串（优化版本）

## 使用方法

### 方法1：运行基础版本（使用示例文字）
```bash
python3 find_common_substrings.py
```

### 方法2：运行优化版本（推荐）
```bash
python3 find_common_substrings_optimized.py
```

### 方法3：运行交互式版本（自定义输入）
```bash
python3 find_common_substrings_interactive.py
```

## 算法说明

该工具使用简单的字符串匹配算法：
1. 遍历第一段文字的所有可能子串
2. 在第二段文字中查找匹配的子串
3. 记录匹配的子串及其位置信息
4. 按长度排序并去重（优化版本）

## 注意事项

- 默认最小重复长度为10个字符
- 支持中文字符
- 区分大小写
- 只查找连续重复的片段
