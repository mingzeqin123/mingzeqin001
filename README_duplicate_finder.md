# 文本重复片段检测器

这个工具可以提取两段文字中连续重复超过10个字符的片段。

## 文件说明

### 1. `text_duplicate_finder.py` - 完整版
功能更全面的版本，提供两种算法：
- **方法1：字符串匹配** - 查找所有可能的重复片段
- **方法2：动态规划最长公共子串** - 使用更高效的算法

### 2. `simple_duplicate_finder.py` - 简化版 (推荐)
优化后的版本，特点：
- 自动去除被包含的较短片段
- 只显示最长的独立重复片段
- 结果更清晰易读

## 使用方法

### 交互式使用
```bash
# 使用简化版（推荐）
python3 simple_duplicate_finder.py

# 使用完整版
python3 text_duplicate_finder.py
```

### 测试模式
```bash
# 简化版测试
python3 simple_duplicate_finder.py test

# 完整版演示
python3 text_duplicate_finder.py demo
```

## 使用示例

### 输入：
```
文本1: 这是一个测试文本，包含一些重复的内容。这个程序可以检测重复片段。
文本2: 另一个测试文本，也包含一些重复的内容。这个程序非常有用。
```

### 输出：
```
============================================================
连续重复超过10个字符的片段检测结果
============================================================
找到 1 个独立的重复片段：

1. 重复片段: "包含一些重复的内容。这个程序"
   长度: 14 字符
   在文本1中的位置: 9-22
   在文本2中的位置: 9-22
```

## 算法说明

程序使用动态规划算法来查找最长公共子串：
1. 创建二维DP表来记录字符匹配情况
2. 当字符匹配时，长度累加
3. 当长度达到阈值（10字符）时，记录该片段
4. 去除被包含的较短片段，保留最长的独立片段
5. 按长度降序排序输出结果

## 特性

- ✅ 支持中文和英文文本
- ✅ 自动去重，避免显示重叠的片段
- ✅ 显示片段在两段文字中的准确位置
- ✅ 可自定义最小重复长度（默认10字符）
- ✅ 提供多个测试示例
- ✅ 处理边界情况（空文本、无重复等）

## 技术细节

- **时间复杂度**: O(m×n)，其中m和n分别是两段文本的长度
- **空间复杂度**: O(m×n)，用于存储DP表
- **编程语言**: Python 3
- **依赖**: 无需额外依赖，使用Python标准库
