📧 用户注册自动邮件发送系统

完整的用户注册解决方案，支持自动发送账户信息邮件

🌟 系统功能

🎯 核心功能

  • 用户注册表单验证
  • 自动生成随机密码
  • 发送精美HTML邮件
  • 包含登录地址信息

📧 邮件内容

  • 用户名和密码
  • 系统登录地址
  • 详细使用说明
  • 安全提示信息

🛠️ 技术特性

  • Node.js + Express后端
  • Nodemailer邮件服务
  • 响应式前端界面
  • 完整的错误处理

🚀 快速开始

步骤 1: 配置邮件服务 - 编辑 backend/.env 文件
# Gmail 配置示例 EMAIL_HOST=smtp.gmail.com EMAIL_PORT=587 EMAIL_USER=your-email@gmail.com EMAIL_PASS=your-app-password EMAIL_FROM=your-email@gmail.com SYSTEM_LOGIN_URL=https://your-platform.com/login SYSTEM_NAME=您的平台名称
步骤 2: 启动后端服务
cd backend npm install npm start
步骤 3: 打开前端页面进行测试
🎯 打开注册页面 📝 查看后端代码

📋 API 接口

POST /api/register Content-Type: application/json { "username": "用户名", "email": "user@example.com" } 响应: { "success": true, "message": "注册成功！账户信息已发送到您的邮箱", "data": { "username": "用户名", "email": "user@example.com", "messageId": "邮件ID" } }
